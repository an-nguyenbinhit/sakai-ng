# Regex Tester - Overview

## 1. Description
A tool that helps users test and debug regular expressions against custom text with live match highlighting.

## 2. Objective
To provide a fast, offline-capable utility for developers to validate their Regex patterns, visualize matching groups, and check for errors efficiently.

## 3. Roadmap
- **Phase 1 (MVP - Minimum Viable Product):** Basic regex evaluation with live highlighting of matches in a test string. Flags support (g, i, m). Match list display.
- **Phase 2 (Advanced Features):** Regex explanation (breaking down parts of the regex), cheat sheet sidebar, capture groups detailing, regex generation or predefined common regexes (email, phone, etc.), and code snippets generator (showing how to use this regex in various programming languages).
