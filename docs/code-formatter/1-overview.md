# Code Formatter - Overview

## 1. Description
A tool that helps users automatically format and beautify source code for various programming languages. 

## 2. Objective
To provide a minimalist, easy-to-use tool that allows developers and end-users to quickly format code with reliable configurations.

## 3. Roadmap
- **Phase 1 (MVP - Minimum Viable Product):** Basic formatting support for common web languages (JSON, JS/TS, HTML, CSS). Static UI for quick input and output.
- **Phase 2 (Advanced Features):** Integration with a professional code editor (with syntax highlighting), expansion to more complex languages (SQL, XML, Markdown, etc.), File Import/Export support, and detailed formatting configurations.
- **Phase 3 (Unit Tests):** Comprehensive unit test suite (117 tests) covering all component behaviors — formatting logic (Prettier + SQL), clipboard, file operations, drag-and-drop, debounce, font size, theme sync, and error paths. All tests run in ChromeHeadless via Karma/Jasmine.
