Help

How to read the number

Owner code First 3 letters. Identifies the owner or principal operator.
Equipment category Fourth letter must be U, J, or Z. U is the standard freight container category.
Serial number Six digits chosen by the owner. OCR errors usually happen here.
Check digit Last digit validates transmission accuracy using the ISO 6346 weighting algorithm.
This tool validates structure and check digit offline only. It does not verify whether a BIC owner code is registered or active.
